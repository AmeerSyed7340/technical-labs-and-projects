# Task 10 — Installed Applications Review  

## Purpose  
To review installed software for outdated programs, unnecessary applications, conflicting tools, or anything that may contribute to system instability, performance issues, or security vulnerabilities. This step helps identify:  
- Applications that should be updated  
- Programs known to cause conflicts  
- Duplicate security tools  
- Unused or high-impact software  
- Recently installed apps that may relate to reported issues  

## Procedure  
1. Open Installed Apps list  
   - Press Windows + I to open Settings  
   - Go to Apps → Installed apps  
   - Ensure the list is sorted by Name or Install date (depending on what you want to analyze)
2. Sort by “Install Date”  
   - Recently installed programs  
   - Potential causes of new issues  
   - Apps installed near the time the problem began  
3. Look for outdated or redundant programs  
   - Old versions of Java  
   - Legacy Microsoft Visual C++ packages  
   - Duplicate software  
   - Old drivers or utilities  
   - Unsupported programs  
4. Identify potentially unwanted or unnecessary software  
   - Game launchers  
   - Tablet drivers (if not needed)  
   - Old Adobe components  
   - Background updaters  
   - Trialware or bundled apps  
5. Confirm presence of expected applications  
   - Web browsers  
   - Drivers  
   - Security software  
   - Productivity tools  
   - Development tools (if applicable)  
6. Flag items needing updates
