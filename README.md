# Technical Labs and Projects

Welcome to my hands-on IT, Networking, and Cybersecurity portfolio.  
This repository showcases real-world troubleshooting labs, ticket simulations, and technical projects I've completed to build practical experience across multiple areas of IT.

Each project is structured like an actual support ticket, with clear documentation of:
- Problem / symptoms  
- Investigation steps  
- Root cause  
- Resolution  
- Verification  
- Screenshots  
- Key learning points  

This mirrors the workflow used in professional Help Desk, Desktop Support, NOC, and SysAdmin environments.
